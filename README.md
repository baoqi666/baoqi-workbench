# BaoQi spaces · 工作台模板

一套以**精力管理**为核心的轻量工作台模板，把「计划 → 专注 → 健康 → 复盘」串成闭环。

- 纯静态 PWA，离线可用，可“安装到手机主屏”当 App 用
- 数据存在各人本地，**分享后每人拿到互不干扰的独立副本**（天然就是模板形态）
- 9 个模块：首页 / 每日计划 / 学有余力 / 自信表达 / 梦想储蓄罐 / 奖励 / 健康 / 运动 / 周复盘
- 核心亮点：精力贯穿全程、专注可量化（番茄钟时长自动折算积分）、积分奖励闭环、本月预算结余自动存入储蓄罐

## 怎么用

1. 打开下方 GitHub Pages 链接（或把本仓库克隆后 `index.html` 直接打开）
2. 手机浏览器打开 → “安装到主屏”，即得到你自己的独立工作台
3. 从「每日计划」开始：加任务、看精力条、点番茄钟，完成时长的积分自动到账

## 本地预览

```bash
# 任意静态服务器，例如
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

> 数据仅存浏览器本地（IndexedDB），换设备或清缓存前请用侧边栏“导出备份”。
